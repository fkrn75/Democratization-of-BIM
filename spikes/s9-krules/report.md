# S9 보고서: 한국 납품 규칙을 기계 검사로 옮길 수 있는가

작성 2026-11-09. 합격 기준: 국토부·조달청·세움터 현행 원문 확보, 규칙 20개 이상을 IDS + 코드로 구현, RA-01과 표본에서 동작.

## 1. 결론

**부분 합격.** 국토부·조달청은 확보와 출처 확인이 끝났다. 세움터 가이드는 공식 파일을 확보하지 못해 미충족이다. 후보 52개를 뽑아 37개를 검사(IDS 18 + 코드 19)로 구현했고 37개 모두 CLI로 실행된다(파일 검사 36개 + 폴더 검사 1개는 `--package`). 시험 48개가 통과한다. 원문이 IFC 속성 이름을 거의 지정하지 않아 구현 요구사항 37개 중 24개는 우리 해석에 의존한다. 독립 검수(조건부 통과, 필수 결함 0) 뒤 에너지 검토 조건부 규칙 3개를 일반 위반 집계에서 분리했고, 망가진 입력이 트레이스백 대신 오류 JSON이 되게 했다.

- REQ-010은 검수 후 5.2.2(3)다(p84) + 5.2.2(4)나(p85)로 정정했다.
- REQ-028은 대리 지표다: 범용객체의 분류 여부(KR-IDS-06)만 본다(`proxy_indicator`).
- IsExternal·열관류율은 조달청 5.2.5(4)나 "에너지 검토 수행 시", 부속서-1 4.2 "환경시뮬레이션 수행 시 선택사항", 설계자편 p56 "(선택 사항)"이므로 KR-IDS-08/09/10을 모두 조건부로 두었다. 후보만 15개(검사 불가 11, 코드 3, IDS 1)는 형상 판정(간섭, 외피 폐합 등)·의도 판정·표준 속성 부재 때문이며 사유를 후보마다 적었다.

주요 근거 조항:
- 조달청 5.2.1·5.5.2: IFC 2x3 이상, 파일명 규칙

## 5. 사람이 확인해야 할 것

1. **IFC 속성 사상은 우리 해석이다**(구현 37개 중 24개). 원문은 "실명·실ID·사업정보를 입력"이라고만 하고 IFC 속성을 정하지 않는다. 가정: 실명=IfcSpace.LongName, 실ID=IfcSpace.Name, 건축규모=Pset_BuildingCommon/Qto_*. 발주처 BIM 담당자 확인이 필요하다.
2. **세움터 가이드 3종은 사람이 세움터 공개자료실에서 받아야 한다.** 받으면 같은 절차로 후보를 추가한다.
3. **문서 간 충돌 3건**(도구는 두 기준을 따로 검사): 단위(조달청 mm 원칙 vs 국토부 m 또는 mm), 열관류율 대상(조달청 6종 vs 국토부 5종), 좌표계(기본지침 UTM52 계열 vs 시행지침 GRS80 TM).
4. **공공누리**: 시행지침은 제4유형(상업 이용 금지, 변경 금지)이다. 저장소에는 원문 없이 요약만 넣었다. 이 요약을 공개 저장소에 두어도 되는지, 상업 제품 근거로 써도 되는지는 법무 확인이 필요하다.
5. **최신 개정 확인**: 국토부 정책정보에는 위 두 건만 나왔고 조달청 v2.2는 찾지 못했다(없다고 단정하지 않음). 유지관리자 편(안)은 2025-01 의견 조회만 확인했다.
6. **구현 범위의 한계**: 실시설계(5장)만 구현했다. 공간 겹침은 경계상자 근사라 비직사각형 방은 오탐할 수 있다. 공간분류코드와 공사코드는 형식만 검사한다. 납품 폴더 구성은 PDF 표가 평탄화돼 해석했으므로 원본 표를 눈으로 봐야 한다.
7. **ifctester 제약**: IDS를 읽을 때 specification identifier를 버려 실행기가 XML에서 따로 읽는다. propertySet 정규식은 일치하는 모든 Pset에 속성이 있어야 통과시켜, 공사코드 존재 검사는 코드로 뒀다. 속성 dataType 지정은 뺐다(IfcLogical·IfcReal 값도 통과). 사용자 정의 Pset에 값을 넣은 모델은 실행기가 08~10을 재판정해 통과로 바꾸지만(`tolerated`), `.ids` 파일을 다른 IDS 도구로 단독 실행하면 여전히 위반으로 나온다.
8. **에너지 검토 여부는 IFC에서 알 수 없다.** 사람이 `--energy`로 알려 줘야 한다.
9. **성능 한도**: 공간 겹침은 같은 층끼리만 비교하고 공간 3,000개를 넘으면 판정을 생략한다. 형상 중복(KR-CODE-17)은 형상 객체 20,000개를 넘으면 생략한다. 100MB급 파일 성능은 미측정이다.
10. **KR-CODE-18(납품 폴더 구성)은 합성 폴더로만 시험했다.** 실제 납품 폴더로는 확인하지 못했다.

## 6. 재현

```
python -m pytest tests -q
python -m krrules.run <ifc> [--deliverable] [--energy] [--package <납품 폴더>] [--as-name 00_건물_BA.ifc] --out result.json
python make_results.py --building-architecture <Building-Architecture.ifc>
PYTHONPATH=. python build_catalog.py
```

python은 전용 venv(ifcopenshell 0.9.0.post1, ifctester 0.9.0, pytest)다. 원문 PDF는 저장소 밖에 둔다. 결과 JSON은 해시 시드와 무관하게 바이트 재현된다(합성 파일의 sha256만 비워 둠).
