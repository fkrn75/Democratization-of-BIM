# 1단계 도면 엔진 기준선과 시트·한글 PDF 글꼴 개선 (2026-11-15)

기준: 공개 기준 체크리스트(법정 별표 2 / 제도·관행 / BIM 지침 3층), 집계 규칙은 G1과 같다(중복 행 제외, 해당없음은 분모에서 제외, 법정 16 = 별표 2 고유 항목이며 높이 3행은 한 묶음으로 판정). 목표는 G2 5-2절(법정 자동 표현 8/8, 제도·관행 충족 40%·충족+부분 70%, BIM 지침 충족 80%·미충족 0).

## 1. 방법

- 입력: RA-01 코어 범위 모델(`spikes/s3-drawings/s3lib.py` build: 레벨 2·벽 14·문 5·뷰 7) + 주석(치수 5·태그 4) + 패밀리 배치(창 2·기둥 1) + 종단면 1. `run_baseline.py --out <폴더>`가 뽑는다. 산출 도면은 저장소 밖(`dobim-local-outputs/phase1-baseline`, `phase1-after`)에 둔다.
- 판정: `judge.py`. G1 판정(`carried_g1.json`: 항목 ID·층·판정만)을 출발점으로 두고, 도면 내용 항목은 기본 산출 SVG가 G1 산출물과 같은지로 유지 여부를 확인하고(기본 7뷰 동일), 시트·글꼴이 바꾸는 9개 항목(N-02, SC-05, SC-06, T-02, T-04, T-05, T-08, LN-06, B-13)은 산출 파일(시트 SVG·PDF)을 직접 검사해 판정한다. 기준선에는 시트 산출이 없어 같은 검사가 '없음'으로 나오고 G1 판정과 일치한다.
- 'RA-01 전체 입력'의 한계: RA-01.ifc 자체를 가져오면 의도(DoBIM_Intent)가 없는 요소는 모두 외래라 도면에 그려지지 않는다. 그래서 G1과 같은 코어 범위 모델을 쓴다. 창·기둥·슬래브·보·계단·공간은 코어가 도면에 그리지 못한다(이번 범위 밖).

- 창: 평면 문 기호(열린 문짝+호)는 `door` 종류에만 그린다. 호스팅된 패밀리 인스턴스(창·패밀리 문)는 패밀리가 평가한 평면 기호를 쓴다(창은 개구부 마구리·벽 면 선·유리 중심선). 입면·단면은 창틀 바깥·안쪽 틀·유리 상자의 모서리를 가림 판정과 함께 그린다.
