# Democratization of BIM

오픈소스 BIM 부품을 조합해 Revit을 부분 대체하는 도구를 만들기 위한 저장소다. 이전 임시명은 RevitAlt였고, `research/` 원본에는 그 이름이 남아 있다. Autodesk와 관련이 없다. Revit은 Autodesk의 상표다.

## 1. 결론

- Revit 전체를 대체하는 오픈소스는 없고, 개인 규모로 Revit 전체를 복제하는 것도 불가능하다.
- 달성 가능한 목표는 **구조·MEP를 쓰지 않는 소형 건물의 IFC 네이티브 저작 + 모델을 따라오는 도면·납품**이다. 전업 1인 + AI 에이전트로 GUI 없는 저작 MVP까지 **약 20.5~37.5인월**, GUI 포함 **약 23.5~43.5인월**이다(모두 추정).
- 추천 경로는 **헤드리스 코어 먼저**다. IfcOpenShell 위에 커맨드 레지스트리·재생성 그래프·패밀리·증분 도면을 만들고, GUI는 선택 패키지로 나중에 얹는다.
- **이전 추천의 대안이던 Bonsai 플러그인은 철회했다.** 아래 제약을 충족하지 못한다. 대신 **ConstructCAD가 유력 대안**이 됐다. 문서상 CLI·MCP 구조가 같고 GPL-3.0이다. S0 결과와 라이선스 결정(D1)이 경로를 가른다.
- 기능 목록은 에이전트로 빠르게 채워지는 시대다. 차별점은 폭이 아니라 왕복 정확도와 증분 일치를 항상 검증하는 체계다.

### 확정 제약 (사용자 지시, ADR-0011)

1. 모든 기능을 MCP나 CLI로 제어할 수 있다.
2. Claude(Claude Code, 데스크톱 앱)와 Codex(CLI, 데스크톱 앱) 양쪽에서 모든 기능을 쓸 수 있다. 한쪽 전용 기능은 없다.
3. 헤드리스 모드: GUI, 디스플레이, GPU 없이 코어 패키지만으로 동작한다. CI와 서버에서 무인 실행된다.

## 2. 현재 상태

- 스파이크 S0~S11의 측정이 끝났다(S6 뷰어는 보류). 코드는 `spikes/` 아래 버릴 코드로 있고, 통합 브랜치가 코어에 S2~S5·S8을 합쳤다. 제품 코드는 아직 없다.
- 승인된 것: ADR-0011의 요구사항, 프로젝트 이름(ADR-0010), G0 결정(경로 F·MPL-2.0 유지, S1 진행). 그 외 ADR과 구현 방식은 "제안"이며 사용자 결정 전이다.
- 다음 할 일: 스파이크 병합 후 G1 판정과 G2 인월 재추정(`docs/roadmap.md` 7절). 미완 항목은 S3 실무 검토자 판정, S7 깨끗한 VM 시험, S9 세움터 원문, S11 Claude 클라이언트 시험, S6 뷰어다.
- `research/05-synaps-check.md`의 "synaps"가 무엇을 가리키는지(상용 SaaS Synaps 또는 SynapsCAD) **사용자 확인 대기** 중이다. 설계에는 반영하지 않았다.

**G1 판정(2026-11-10)**: 조건부 통과. 코어(S1·S2·S10)는 합격 기준을 모두 충족했고 실패는 S3 실무 판정 1건이다. 실무 검토자 대신 공개 기준(건축법 시행규칙 별표 2 등) 128항목으로 RA-01 도면을 대조했다. 우리 도면은 허가 초안으로 쓸 수 없으며, Revit 2025 기본 출력도 법정 층에서 같은 수준이다. 조건: 1단계 착수 전 S11 Claude 시험, S3 결손 목록을 1단계 도면 엔진 작업으로 편입. 상세는 [g1-gate.md](docs/g1-gate.md).

**G2 판정(초안, 2026-11-14)**: 1단계 착수 권고(조건부, 최종 판정은 사용자). 인월을 실측으로 다시 쓰니 1단계 8.8~18.8PM(이전 9~17.5PM), GUI 포함 MVP 20.0~41.0PM(이전 23.5~43.5PM)이다. 줄어든 폭은 대부분 스파이크 행이고 도면 엔진이 늘었다. S3 도면 합격 기준은 "모델에 정보가 있는 법정 항목 전부 자동 표현"으로 다시 정의했다. 착수 전 조건 C-1(S11 Claude 시험)은 진행 중이다. 상세는 [g2-gate.md](docs/g2-gate.md).

## 6. 불확실한 점

- 인월 수치는 측정 전 추정이다. 스파이크 결과를 반영한 재추정은 G2에서 한다.
