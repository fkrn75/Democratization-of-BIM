# G1 관문 판정

기준일 2026-11-10. 대상은 로드맵 7절의 G1이다. G1이 묻는 것은 "코어가 믿을 만한가"다. 실패 항목이 2개 이상이면 범위를 줄이거나 후보 도구 기여로 전환한다.

## 1. 결론

**조건부 통과.** 코어(S1·S2·S10)는 합격 기준을 모두 충족했다. 실패는 S3의 "실무 검토자 판정" 1개다. S11 Claude 쪽은 측정하지 않았으므로 실패로 세지 않고 미완으로 둔다. 실패가 1개이므로 범위 축소나 기여 전환 없이 G2로 간다. 다만 아래 두 조건은 1단계 완료 전에 반드시 닫는다.

| 조건 | 내용 | 닫는 시점 |
|---|---|---|
| C-1 | S11 Claude 클라이언트 종단 시험(층 C, 결과 동등, 탐색 20개, 이미지 판정). 패리티 A는 ADR-0011 확정 제약이다 | 1단계 착수 전 |
| C-2 | S3 도면 결손 목록(3-3절)을 1단계 도면 엔진 작업으로 편입하고, S3 합격 기준의 사람 판정을 공개 기준 3층 대조로 다시 정의 | G2 재추정에 반영 |

## 3. S3 실무 판정을 공개 기준으로 대신한 방법

실무 검토자를 확보하지 못해, 웹에서 공개로 확보할 수 있는 기준 문서로 판정을 대신했다.

### 3-1. 기준 문서

| 문서 | 버전·날짜 | 비고 |
|---|---|---|
| 건축법 시행규칙 [별표 2] 건축허가신청에 필요한 설계도서 | 국토교통부령 제1567호 본문(2026-02-27 시행), 별표 개정 표기 2021-06-25 | 정본. 허가 표시사항 16개(배치도 6·평면도 5·입면도 3·단면도 2), 축척은 "임의" |
| 같은 규칙 [별표 4의2]·[별표 3] | 위와 같음 | 상한 점검용 |
| 건축물의 설계도서 작성기준 | 국토교통부 고시 제2024-907호(2024-12-31 시행) | 실시설계 도면 축척 1/100 이상 |
| KS F 1501 건축 제도 통칙 | 최종 확인 2025-05-02 | 원문 유료, 개요만 확인. 세부는 민간 제도 지침으로 대체(신뢰도 낮음) |
| 건설산업 BIM 시행지침 설계자편 | 국토교통부, 2022-07 | 도면 추출 원칙, 2D 주석 추가 허용 |
| 조달청 시설사업 BIM 적용지침서 | v2.1, 2022-12-28 | 최소 도면 대상 |

법정 최소 기준은 얇다. 치수·표제란·선 굵기는 법령에 없고 고시·KS·관행으로 위임된다. 그래서 판정을 **법정(별표 2) / 제도 통칙·관행 / BIM 지침** 세 층으로 나눴다. 체크리스트는 128항목(대조 대상 123)이다.

### 3-2. 대조 결과

RA-01을 두 도구로 그려 같은 체크리스트로 판정했다.

- **우리 도구**: main 코어가 만든 평면·단면·입면 7뷰(SVG·PDF). 코어 범위 모델은 벽·문·레벨뿐이다. 주석 커맨드(`annot.*`)로 치수·태그를 추가한 판을 포함했다.
- **Revit 2025 기본 출력(참조)**: RA-01 IFC를 Revit으로 열고 평면 2·단면 1·입면 4를 1:100으로 만들어 A1 시트 4장으로 내보냈다. 사람 손 주석은 0이다. 자동화는 별도 저장소 dobim-revit-bridge의 `drawings.export_set` 커맨드로 했다. Revit 산출 파일은 공개하지 않는다.

| 층 | 우리(충족/부분/미충족/해당없음) | Revit 기본 출력 |
|---|---|---|
| 법정 별표 2 (16) | 3 / 2 / 11 / 0 | 3 / 3 / 10 / 0 |
| 제도 통칙·관행 (78) | 14 / 22 / 36 / 6 | 20 / 20 / 32 / 6 |
| BIM 지침 (18) | 6 / 8 / 1 / 3 | 8 / 7 / 0 / 3 |
| 합계 (112) | 23 / 32 / 48 / 9 (충족 22%) | 31 / 30 / 42 / 9 (충족 30%) |

주의: 우리 판정은 주석 커맨드를 추가로 호출한 결과를 인정했고, Revit은 기본 출력만 봤다. 우리 기본 출력만 보면 법정 층은 2 / 3 / 11이다.

**판정: 우리 도면은 허가 초안으로 쓸 수 없다.** 다만 Revit 기본 출력도 법정 층에서 같은 수준으로 불가다. 허가 도면은 어느 도구든 자동 추출 뒤에 사람이 치수·방화 표기·배치도 등을 그려 넣어 완성한다는 뜻이다. 따라서 S3 기준을 "사람 판정 통과"에서 "공개 기준 3층 대조에서 목표 충족률 달성"으로 다시 정의한다(C-2). 목표치는 G2에서 정한다.

### 3-3. 결손 분류

**Revit은 충족, 우리는 미충족 (도면 엔진의 실제 결손)**

1. 시트·표제란·도면번호·용지·윤곽선·개정란
2. PDF 한글 글꼴 미내장(한글이 `?`로 깨짐), 문자 크기 체계
3. 창이 문 열림 호로 그려짐, 기둥이 평면·단면에 안 나옴
4. 평면의 단면·입면 기호
5. 실명·실번호, 계단·슬래브 표현(일부는 코어 모델 범위 차이)
6. 상세 수준·선 굵기 체계

**Revit 기본 출력도 미충족 (어느 도구든 자동화 대상, 차별화 후보)**

1. 치수 일체(Revit 기본 출력도 치수 0개)
2. 방화구획·방화문 등 방화 표기
3. 배치도·대지(입력 자료 필요)
4. 외부 마감·재료 표기와 해치, 반자 높이
5. 방위·그리드·레벨 주기
6. 도면 목록·범례·키플랜·서명·개정 이력
7. 창호 부호·일람표, 상세도

### 3-4. 한계

- KS F 1501 원문을 보지 못해 제도 통칙 층은 민간 지침으로 대신했다. 이 층의 판정은 신뢰도가 낮다.
- 두 도구의 입력이 다르다. Revit은 원래 RA-01 IFC(창·슬래브·기둥·계단·공간 포함)를 열었고, 우리 코어 범위 모델은 벽·문뿐이다. 판정표에 원인(표현 능력/입력 차이)을 나눠 적었지만 완전한 같은 조건 비교는 아니다.
- 사람 실무자의 판정을 대신한 것이지 같은 것은 아니다. 실무자를 확보하면 다시 판정한다.
