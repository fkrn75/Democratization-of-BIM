# ADR-0009. .rvt/.rfa 호환은 MVP 의존성에서 제외

- 상태: **제안**
- 일자: 2026-11-07

## 맥락

- rvt-rs(Apache-2.0)는 "컨테이너 수준"이 아니다. README 지원표상 Revit 2023~2025는 요소 레코드를 해독해 IFC4로 내보낸다. 다만 2015~2022·2026·2027은 실험 단계이고, 요소 본체는 대부분 바운딩박스이며, 패밀리 파일에는 지오메트리가 없고, 쓰기는 스트림 바이트 패치뿐이다(반증 검토에서 확인. 02문서 4절의 해당 서술을 정정함). 1인 개발 비중이 높다.
- ODA BimRv는 상용이고 쓰기 범위가 제한적이다.
- 역공학의 법적 위험은 별도다(02문서 4절).

## 결정 (제안)

- 정식 전환 경로는 **Revit의 IFC 내보내기 → 가져오기**다.
- MVP는 어떤 .rvt 파서에도 의존하지 않는다.
- rvt-rs는 **연구 트랙의 선택적 가져오기**로 둔다. 별도 프로세스로 호출하고, 결과는 근사 형상의 동결 요소로 표시하며, 법무 확인 전에는 배포에 넣지 않는다.
- .rvt 쓰기는 목표로 삼지 않는다.

## 영향

Revit 원본 제출을 요구하는 발주처, .rvt로 협업하는 파트너와는 일할 수 없다. 타깃 설정(ADR-0002)에 이 제약을 반영한다.

## 뒤집는 조건

rvt-rs가 실제 프로젝트에서 본체 형상까지 안정적으로 복원하고 법무 의견이 나오면 가져오기 기능으로 승격을 재검토한다.
