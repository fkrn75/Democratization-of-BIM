# ADR-0003. 라이선스

- 상태: **승인: MPL-2.0** (사용자 결정 D1, 2026-11-07). 엔지니어링 판단이며 법률 자문이 아니다. 공개 전 법무 확인 권장.
- 일자: 2026-11-07

## 선택지별 영향

| IfcOpenShell(LGPL) | 사용 가능 | 사용 가능 | 사용 가능. onedir 동봉, EULA에 역공학 예외 필수 | 사용 가능 |

| 유료 플러그인·클라우드 | 가능 | 코드 공개 조건 또는 저작권자 이중 라이선스 | 자유 | 가능 |

## 결정 (승인)

코어·앱은 **MPL-2.0**. Bonsai 어댑터를 만들 경우 그 패키지만 GPL-3.0으로 분리한다.

이유: 사용자가 이미 공개 저장소 활동을 하고 있고, IFC 생태계의 ifc-lite·web-ifc와 같은 라이선스라 교류가 쉽다. GPL 호스트와도 결합할 수 있다. 상용화 여지(유료 플러그인·서비스)도 남는다.

## 라이선스와 무관하게 지키는 규칙

1. **GPL 코드를 구현 에이전트의 컨텍스트에 넣지 않는다.** L1·L3·L4에서 Bonsai·ConstructCAD의 소스를 읽혀 구현하면 파생물 시비가 생긴다. 문서·동작 관찰·IFC 산출물만 참고한다. BimCraft(Apache)와 ifc-lite(MPL)는 읽어도 되지만 복사 시 고지·파일 단위 조건을 따른다.
   - 조사 단계에서 팀이 ConstructCAD `view.rs`와 Bonsai `drawing/operator.py` 소스를 사실 확인 목적으로 열람했다. 구현 에이전트는 격리한다. `research/03`의 요약만 받고 해당 소스를 열지 않는다.
2. IfcOpenShell 동봉은 라이브러리 파일을 별도로 두어 교체할 수 있게 하고, GPL·LGPL 사본과 고지를 동봉한다. COPYING.LESSER 4항 d-1(공유 라이브러리 메커니즘) 또는 d-0(재링크 자료)을 충족하는 구현 선택으로 **PyInstaller onedir를 권장**한다(추정, 법무 확인 필요. 4항이 onedir를 직접 언급하지는 않는다). onefile은 쓰지 않는다. 휠에 포함된 OCCT(LGPL-2.1+예외)도 고지한다.
3. AGPL 부품(xeokit, BIMserver, Chili3D, bldrs conway)은 L2가 아니면 넣지 않는다.
4. 의존성 라이선스 목록을 CI에서 검사한다.

## 불확실

- 에이전트가 생성한 코드의 저작권 귀속이 불명확하다. L3·이중 라이선스처럼 "저작권 보유"에 기대는 모델에서 문제가 될 수 있다. 확인 전까지 이 모델에 의존하지 않는다.
- 외부 기여를 받을 때 DCO와 CLA 중 무엇을 쓸지 미정이다. 나중에 이중 라이선스를 하려면 CLA가 필요하다.

## 다르게 정하면 바뀌는 것

- L2: 설계 참고 제한이 풀린다. 다만 코어가 Python이라 Rust(ConstructCAD)를 직접 쓸 일은 적고 Bonsai 쪽 이득이 크다. ADR-0001의 경로 A의 매력이 커진다.
- L3: Bonsai 어댑터를 포기한다. ODA 상용 경로 검토가 가능해진다. EULA 조항 작성이 필요하다.
