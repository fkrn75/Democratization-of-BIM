# ADR-0010. 제품명과 상표

- 일자: 2026-11-07
- 상태 구분:
  - **프로젝트 이름: 승인** (2026-11-07 사용자 결정)
  - **짧은 식별자: 제안**

## 결정

- 프로젝트 이름은 **Democratization of BIM**이다.
- 저장소·폴더 표기는 **`Democratization-of-BIM`**이다. 공개 GitHub 저장소로 시작한다.
- 이전 임시명은 `RevitAlt`였다. `research/` 원본에만 남아 있다.

## 짧은 식별자 (제안)

코드, 패키지, Pset, 확장자에 전체 이름은 길다. 문서는 아래 후보를 전제로 쓴다.

| 쓰는 곳 | 제안 |
|---|---|
| CLI, MCP 서버 이름 | `dobim` |
| 패키지 | `dobim-core`, `dobim-gpu`, `dobim-app` |
| MCP 도구 접두사 | `dobim_` |
| IFC Pset | `DoBIM_Intent` |
| 프로젝트 파일 | `.dobim` |

- 대안은 `demobim`, `openbim-d` 등이다. `dobim`이 가장 짧아 도구 이름 길이에 유리하다.
- PyPI·npm·GitHub 이름 중복과 등록상표는 아직 확인하지 않았다. 패키지를 처음 올리기 전에 확인한다.
- 파일 형식과 Pset 이름은 공개 후 바꾸기 어렵다. 패키지 첫 배포 전에 확정한다.
- 샘플 건물 이름 `RA-01`은 제품명이 아니므로 유지한다.

## 상표 규칙 (유지)

- Revit은 Autodesk의 상표다. 제품명, 패키지명, 저장소명, 도메인, 실행 파일, 로고, 파일 확장자에 "Revit" 또는 유사 표기를 쓰지 않는다.
- 호환성 설명이 필요하면 "Revit에서 내보낸 IFC를 읽습니다"처럼 사실만 적고, 제휴로 오해할 표현을 쓰지 않는다.
- 법률 자문이 아니다.
- BimCraft 포크로 경로가 바뀌면 그쪽 TRADEMARKS.md에 따라 이름 변경이 필요하다는 점은 현재 이름과 무관하다.
