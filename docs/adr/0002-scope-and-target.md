# ADR-0002. 범위와 타깃 사용자

- 상태: **제안** (사용자 결정 D2)
- 일자: 2026-11-07

## 맥락

개인 + AI 에이전트 규모로 Revit 전 범위 복제는 불가능하다. 또 수요와 도달 범위가 어긋나는 문제가 있다.

- 공공 BIM 의무 대상은 500억 원 이상(2026 예정)처럼 대형 공사다(02문서, 2차 자료·이행 미확인). 대형 프로젝트는 다인 협업과 대형 모델 성능, MEP가 필요하다.
- 현실적으로 도달 가능한 저작 범위는 소형 건물이다. 세움터 BIM 인허가는 단독·공동주택·오피스텔을 제외한다고 보고됐다(02문서, 2차).

즉 "의무 납품 수요는 대형, 만들 수 있는 저작 도구는 소형"이다. 시장성은 **미검증**이다.

## 선택지

| 안 | 사용자 | 장점 | 영향 |
|---|---|---|---|
| T1 (추천) | IFC를 내야 하는 소규모 사무소 + BIM 담당자·자동화 개발자 | 1단계 검사·도면 도구가 Revit 산출 IFC에도 쓰여 대형 수요에 닿음 | 읽기 전용 성능 목표 5만 요소 필요 |
| T2 | 학습·연구·포트폴리오 | 시장 부담 없음. 공개 저장소 친화 | 한국 납품 기능 우선순위 하락, 범위 축소 가능 |
| T3 | 중대형 설계사의 Revit 교체 | 수요가 분명 | 협업·MEP·패밀리 자산 필요. 개인 규모 불가 |

## 결정 (제안)

T1. 저작 MVP의 대상은 **건축 분야, 비주거 소형 건물, 연면적 약 3,000㎡, 5,000요소 이하**(수치는 설계 목표로 잡은 추정치)다.

MVP에서 뺀다: 구조 해석·철근, MEP, 렌더링, 에너지 해석, Phase·Design Option UI, 워크셰어링, .rvt 직접 호환, DWG 직접 쓰기, 패밀리 에디터 GUI. 단 데이터 모델 자리는 남긴다(ADR-0005).

02문서의 "MVP 필수 묶음" 중 DWG는 DXF로 낮췄다. DWG 쓰기는 ODA 약관이 불명확하기 때문이다.

## 다르게 정하면

- T2: 납품 검사(S9)를 빼고 저작 쪽을 앞당긴다. 범위에서 약 1~2인월 절감.
- T3: 이 설계로는 도달하지 못한다. 경로를 다시 논의해야 한다.

## 뒤집는 조건

실무자 인터뷰 3건 이상에서 1단계 도구에 쓸 이유가 없다는 답이 나오면 T2로 낮춘다. 건축 실무 검토자 없이 진행하면 도면 품질 판정을 믿을 수 없다(`docs/roadmap.md` 위험 표).
