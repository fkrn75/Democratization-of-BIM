# ADR-0007. 형상: 2.5D 우선, 커널은 직접 만들지 않음

- 상태: **제안** (S1·S3로 검증)
- 일자: 2026-11-07

## 결정 (제안)

세 단계로 나눈다. 단순한 경로부터 시도한다.

1. **프리즘 경로(대부분의 건축 요소)**: 평면 프로파일 + 높이 범위. Clipper2(BSL-1.0)나 shapely로 조인과 평면 연산을 한다.
2. **메시 불리언**: 표시용 개구부 차감은 Manifold(Apache-2.0, `manifold3d` 휠).
3. **정밀 경로**: 경사 지붕, 스윕, 외래 요소는 IfcOpenShell 지오메트리 반복기(내부 OCCT 등)를 쓴다. OCCT를 직접 바인딩하지 않는다.

IFC 출력은 메시가 아니라 의미 있는 형식으로 한다. SweptSolid + `IfcOpeningElement` + `IfcRelVoidsElement` + `IfcRelFillsElement`이다.

프리즘 경로와 IfcOpenShell의 계산 결과를 CI에서 비교한다(체적 오차 0.1% 이내 목표).

## 위상 명명 문제 회피 (핵심 규칙)

**면·모서리를 인덱스로 참조하지 않는다.** 치수, 태그, 호스팅은 요소가 공개한 의미 참조만 쓴다. 예: `wall:<id>#face=exterior`, `wall:<id>#end=start`, `door:<id>#ref=center`. 패밀리는 참조 평면 이름을 공개한다. 이 규칙이 FreeCAD 계열에서 알려진 위상 명명 문제를 피하는 주 수단이다.

## 대안

| 대안 | 기각 이유 |
|---|---|
| OCCT를 모든 요소에 사용 | 느리고 불리언 실패 처리 비용이 크다. BIM 요소 대부분은 B-rep이 필요 없다 |
| truck 등 Rust 커널 | BIM 규모 검증 없음 |
| ifc-lite 정확 산술 CSG | 후보로 유지(S6). 저자 주장은 미검증 |
| 자체 커널 | 개인 규모에서 불가 |

## 한계

곡면 벽, 비정형 지붕, 매스 모델링은 MVP 범위 밖이다. 정밀 경로로 표시는 되지만 파라메트릭 편집은 제한된다.
