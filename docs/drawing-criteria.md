# 허가 신청 도면 공개 기준 체크리스트 (요약본)

> **용도**: 1단계 도면 엔진이 만든 허가 신청용 평면·입면·단면 도면을 항목별로 판정하는 기준이다. [g2-gate.md](g2-gate.md) 5절의 법정 자동 표현 목표(8항목)와 제도·관행, BIM 지침 층 충족률 목표가 이 목록을 분모로 쓴다.
>
> **한계 1**: KS F 1501 원문을 열람하지 못했다. 선·문자·표제란·치수의 세부 값은 민간 공동지침 사본으로 대체했고 등급은 C(구속력 없는 참고 기준)다.
>
> **한계 2**: 설계도서 작성기준은 민간 사본으로 읽었고 정본을 대조하지 못했다. 2026년 행정예고 개정안의 확정 여부도 미확인이다.
>
> **한계 3**: 실무 검토자의 판정이 아니다. 공개 기준 대조 결과이며, 허가 신청용 도면의 최종 적합성을 보증하지 않는다. 등급 X 항목과 "미확인" 표기 항목은 판정 시 미확인으로 둔다.
